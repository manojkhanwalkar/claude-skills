# Sources

- RFC 9110, HTTP Semantics (methods, safety, idempotency, status codes, conditional requests): https://www.rfc-editor.org/rfc/rfc9110
- RFC 9457, Problem Details for HTTP APIs (obsoletes RFC 7807): https://www.rfc-editor.org/rfc/rfc9457
- RFC 9745, The Deprecation HTTP Response Header Field: https://www.rfc-editor.org/rfc/rfc9745
- RFC 8594, The Sunset HTTP Header Field: https://www.rfc-editor.org/rfc/rfc8594
- RFC 8288, Web Linking (`Link` header, pagination links): https://www.rfc-editor.org/rfc/rfc8288
- RFC 3339, Date and Time on the Internet; RFC 7396, JSON Merge Patch; RFC 6902, JSON Patch.
- IETF httpapi working group drafts: The Idempotency-Key HTTP Header Field (`draft-ietf-httpapi-idempotency-key-header`, draft-08 in 2026) and RateLimit header fields (`draft-ietf-httpapi-ratelimit-headers`): https://datatracker.ietf.org/wg/httpapi/documents/
- Zalando RESTful API and Event Guidelines (CC BY 4.0): https://opensource.zalando.com/restful-api-guidelines/
- Microsoft REST API Guidelines: https://github.com/microsoft/api-guidelines
- Google API Design Guide (resource-oriented design, standard methods, errors): https://cloud.google.com/apis/design
- OWASP API Security Top 10 (2023): https://owasp.org/API-Security/editions/2023/en/0x11-t10/
- Stoplight Spectral and its OpenAPI ruleset: https://docs.stoplight.io/docs/spectral/
- oasdiff (OpenAPI breaking-change detection): https://github.com/oasdiff/oasdiff
- Spring Framework reference, Error Responses (`ProblemDetail`, `ErrorResponse`): https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-ann-rest-exceptions.html
